# VRM animations

Upload `.vrma` files to this folder, then push to `main`. GitHub Pages rebuilds
and automatically includes all files ending in `.vrma` (case insensitive).

One animation is chosen randomly on each page refresh. It plays on a shared
timeline while the avatars change, then completes its current loop on Bocchi
and holds the last pose. Use clips with a comfortable ending pose.

`VRMA_02.vrma` is the animation supplied for this site. Only add animations you
have permission to publish. No conversion to sampled or procedural motion is
performed: three-vrm-animation retargets the VRMA tracks directly to each avatar.
